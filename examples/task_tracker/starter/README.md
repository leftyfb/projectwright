# Task Tracker (Projectwright starter)

A small local command-line task tracker is the goal of this repository. It will use Python's standard library and a JSON database. The application and tests have not been implemented yet; follow the Projectwright task-tracker example walkthrough to initialize, plan, and develop this disposable project.

Intended commands: add a task, list tasks, and mark a task complete. No network access, credentials, cloud services, or third-party packages are in scope.
