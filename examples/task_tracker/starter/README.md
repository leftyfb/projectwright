# Task Tracker Example (Projectwright starter)

This is the starter `README.md` for the **`task-tracker-example`** Git repository at `~/projects/task-tracker-example/` (or a custom location selected during `pw init`). Projectwright's definitions, queue, and state belong inside that repository's `.pw/` directory.

The goal is a local task-tracking command-line application built with Python's standard library and a JSON database. The application and tests have **not been implemented yet**. Follow the [Projectwright Task Tracker walkthrough](https://github.com/leftyfb/projectwright/blob/main/examples/task_tracker/README.md) to initialize the project, add requirements, plan, develop, and approve milestones.

Intended commands: add a task, list tasks, and mark a task complete. No network access, credentials, cloud services, or third-party packages are in scope.
